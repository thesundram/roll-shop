# RollShop MES - Steel Mill Management System

RollShop is a comprehensive Manufacturing Execution System (MES) specifically designed for Steel Mill Roll Shop operations. It streamlines grinding operations, inventory management, production reporting, and real-time analytics to ensure maximum efficiency and quality in roll maintenance.

## 🚀 Features

- **Executive Dashboard**: Real-time overview of grinding operations, tonnage trends, and machine productivity.
- **Grinding Log Management**: Digital recording and tracking of all grinding operations with detailed parameter logging.
- **Inventory Control**: Comprehensive tracking of rolls, grinding wheels, and other shop consumables.
- **Production Reporting**: Automated generation of production summaries, trends, and performance metrics.
- **Roll History Tracking**: Complete lifecycle tracking for every roll, including total tonnage, grinding frequency, and current status.
- **Alert System**: Real-time notifications for critical operational events and maintenance requirements.
- **Modern UI/UX**: Premium dark-mode interface built with Next.js, Tailwind CSS, and Shadcn UI.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [Shadcn UI](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts**: [Recharts](https://recharts.org/)
- **Theme**: [Next Themes](https://github.com/pacocoursey/next-themes)

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd RollShop
   ```

2. Install dependencies:
   ```bash
   pnpm install
   ```

3. Run the development server:
   ```bash
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🏗️ Project Structure

- `/app`: Next.js App Router pages and layouts.
- `/components`: Reusable UI components and dashboard-specific modules.
- `/lib`: Utility functions and shared logic.
- `/public`: Static assets and images.
- `/styles`: Global styles and Tailwind configuration.
